聊天消息头像验证

运行分组和布局测试（macOS，无需模拟器）：

```sh
bash Modules/WuKongBase/Tests/run-avatar-layout-tests.sh
```

测试直接编译生产代码 `WKMessageAvatarLayout.m`，覆盖组尾不在可见 Cell 中、超长消息、底部吸附与自然位置切换、可视区域裁剪、多个发送者、键盘高度变化、多选布局，以及插入历史消息、追加消息、删除和分组拆分/合并后的稳定身份。

实现分工：

- `WKMessageAvatarLayout` 处理消息分组和位置计算，不依赖 UIKit 或消息 SDK。
- `WKMessageAvatarController` 持有每个可见组的头像。头像层放在表格内部，拖动头像时仍由表格的 pan 手势处理；空白区域不拦截事件。
- `WKConversationTableView` 在数据变化时通知分组失效，布局结束后刷新头像；滚动只计算可见消息的位置。
- `WKMessageCell` 保留头像占位布局，由列表接管时隐藏内部头像并停用其点击区域。独立使用的消息 Cell 保留原有头像显示方式。

设备验收步骤（自动测试不覆盖 UIKit 手势、动画及网络图片加载）：

1. 在群聊中让同一发送者连续发送多条文字、图片和一条超长消息。上下拖动及快速甩动：每组只有一个头像，组尾在屏幕下方时停在输入框上方，组尾出现后跟随气泡底部。
2. 在不同发送者、日期、系统消息和撤回消息之间滚动，确认头像分组正确；单聊和自己发出的消息不显示左侧头像。
3. 在同一组中加载历史消息、接收新消息、删除消息、更新头像和调整图片/流式消息高度，确认不串头像、不残留旧位置。
4. 从头像开始拖动列表；单击头像查看资料；长按头像 @ 对应成员。进入多选后头像回到组尾，头像区域可以选择消息。
5. 展开/收起键盘、表情面板以及多选面板，确认头像随实际消息可视区域变化且不覆盖输入框。
